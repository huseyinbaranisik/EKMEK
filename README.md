## 🇬🇧 English

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> About the Project
**Ekmek** is a sleek, modern, voice-controlled AI assistant for Windows. It uses the Groq API (Llama 3 and Whisper) for fast and intelligent interactions.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Features
- 🎙️ **Voice commands:** High-accuracy speech recognition with Whisper-large-v3.
- 🧠 **Intelligent interpretation:** Intent analysis and contextual memory with Llama-3.3-70b.
- 💻 **System control:** Brightness, volume, keyboard backlight and media keys.
- 🎵 **Spotify integration:** Search songs, start playlists and auto-play.
- 🚀 **App launcher:** Instantly open saved applications and system tools.
- 🎭 **Custom modes:** Gaming, Night and Daily modes change several settings with one command.
- 🎨 **Modern UI:** Glassmorphism design with smooth animations.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Setup
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file and add your `GROQ_API_KEY`.
4. Run `npm start` to launch the assistant.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Tech Stack
- Electron.js
- Groq Cloud API (Llama & Whisper)
- PowerShell (for system integration)
- Vanilla JS & CSS

## 🇹🇷 Türkçe

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> Proje Hakkında
**Ekmek**, Windows işletim sistemi için geliştirilmiş, sesli komutlarla çalışan, şık ve modern bir yapay zeka asistanıdır. Groq API (Llama 3 ve Whisper) kullanarak hızlı ve akıllı yanıtlar verir.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Özellikler
- 🎙️ **Sesli Komutlar:** Whisper-large-v3 ile yüksek doğrulukta ses tanıma.
- 🧠 **Akıllı Yorumlama:** Llama-3.3-70b ile kullanıcı niyetini anlama ve bağlamsal hafıza.
- 💻 **Sistem Kontrolü:** Parlaklık, ses düzeyi, klavye arka ışığı ve medya kontrolleri.
- 🎵 **Spotify Entegrasyonu:** Şarkı arama, çalma listesi başlatma ve otomatik oynatma.
- 🚀 **Hızlı Uygulama Başlatma:** Kayıtlı uygulamaları veya sistem araçlarını anında açma.
- 🎭 **Özel Modlar:** Oyun, Gece ve Günlük modları ile tek komutla birden fazla ayar.
- 🎨 **Modern Arayüz:** Cam morfolojisi (Glassmorphism) tasarımı ve şık animasyonlar.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Kurulum
1. Bu projeyi klonlayın.
2. `npm install` komutu ile bağımlılıkları yükleyin.
3. `.env` dosyası oluşturun ve `GROQ_API_KEY` anahtarınızı ekleyin.
4. `npm start` ile asistanı başlatın.
